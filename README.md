# Campus Connect — KLE Tech Hubli

**Campus Connect** is a centralized, interactive web application built specifically for students, faculty, and student organizations at **KLE Technological University, Hubli**. Designed as a single, modern digital portal, it replaces scattered link trees, social media posts, and fragmented messaging groups with a real-time, unified event and organization directory.

---

## 🌟 Key Features

* **Recruiting Now Section:** Real-time visibility into active club recruitments, audition schedules, and application links across campus.
* **Filterable & Searchable Events Directory:** Explore upcoming campus fests, workshops, and gatherings with integrated date/venue tags, custom search, and direct registration links.
* **Interactive Club Directory:** Complete profiles for all recognized campus organizations, sorted by category (Technical, Cultural, Motorsports, Literary, Career Prep, Media, and Entrepreneurship).
* **Smart Dynamic Buttons:** Social media, email, and external registration links automatically display only when valid data exists, avoiding broken or dead links.
* **Weekly Campus Pulse:** Features recurring events—such as the Friday HUB Meet—keeping the student body engaged with ongoing activities.
* **Announcements Feed:** Centralized notice board for official updates from student clubs and the Student Senate Council (SSC).
* **Mobile-Responsive & Modern Design:** Styled with custom CSS, dark-mode glassmorphism, responsive navigation, and reduced-motion accessibility support.

## 💡 Why It Matters

Finding information on college events and club activities often requires navigating multiple Instagram pages or WhatsApp groups. Campus Connect streamlines campus discovery into an intuitive, accessible web platform—helping student organizations reach wider audiences while enabling students to easily get involved in college life.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Glassmorphism, Flexbox, CSS Grid)
* **Scripting:** Vanilla JavaScript (ES6+, DOM Manipulation, IntersectionObserver API)
* **Typography:** Google Fonts (*Fraunces* & *Inter*)
